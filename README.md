# LUMINAA
**Цифровой ассистент врача для анализа МРТ головного мозга и поддержки врачебных решений.**

LUMINA — это веб-платформа, которая автоматизирует рутинные этапы диагностики, выстраивает единый клинический цикл между неврологом и рентгенологом и помогает врачу не упустить важные детали. 

## 🎯 Проблема и решение
**Проблема:** Долгий путь от жалобы до заключения, разрозненность данных (снимки отдельно, бумажные карты отдельно), риск человеческой ошибки при просмотре большого объема снимков.
**Решение:** Единая цифровая среда, где невролог и рентгенолог работают в одном окне. Система автоматически проверяет качество снимков, выделяет подозрительные области и сверяет текст жалоб с результатами снимков.

## ✨ Ключевые возможности

*   **Две независимые модели:**
    1.  **Анализ снимков:** Свёрточная нейросеть (ResNet-18) классифицирует МРТ на 4 класса (глиома, менингиома, аденома гипофиза, без опухоли) и строит тепловую карту (Grad-CAM), показывая, на что она смотрела.
    2.  **Анализ жалоб:** Текстовый алгоритм (TF-IDF + ключевые слова) сопоставляет жалобы пациента с клиническими описаниями и сравнивает свой вывод с результатом нейросети. При расхождении — выдает предупреждение.
*   **Контроль качества (QC):** Автоматическая отбраковка снимков низкого качества до отправки их в модель.
*   **Полный клинический цикл:** 
    Первичный приём (невролог) → Направление на МРТ → Загрузка снимков и заключение (рентгенолог) → Повторный приём и назначение лечения (невролог).
*   **Разграничение прав (RBAC):** Роли `Администратор`, `Невролог`, `Рентгенолог`. Каждый видит только свои этапы.
*   **Автогенерация PDF:** Формирование брендированных отчетов для каждого этапа приема.
*   **Аудит действий:** Журналирование всех операций в системе.

## 🛠 Технологический стек
*   **Backend:** Python 3.12, Flask, Flask-Login, Flask-SQLAlchemy
*   **ML/CV:** PyTorch, torchvision, OpenCV, scikit-learn, Grad-CAM
*   **База данных:** PostgreSQL
*   **Frontend:** Jinja2, Bootstrap 5, HTML/CSS, Vanilla JS
*   **PDF:** ReportLab (с поддержкой кириллицы)
*   **Инфраструктура:** Docker, Docker Compose, Gunicorn

## 📊 Метрики модели классификации
Модель обучена на открытом датасете Kaggle (Brain Tumor MRI Dataset). 
*   **Accuracy (Точность):** 98.25%
*   **F1-macro:** 98.24%
*   **Лучший класс:** «Без опухоли» (0.993) — минимизирует ложноположительные срабатывания.
*   **Сложный класс:** «Менингиома» (0.974) — визуально схожа с глиомой.

> *Модель протестирована на 1200 снимках. Результат не является медицинским заключением.*
